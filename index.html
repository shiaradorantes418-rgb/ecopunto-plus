¿Cómo funciona Ecopunto+?

El usuario participa directamente en el proceso de reciclaje: separa sus residuos, los deposita correctamente, registra su depósito y recibe puntos para obtener beneficios.

Identifica el tipo de residuo.

3

4

Acumula

5

Recompensa

Canjea tus puntos por beneficios.

Separa tus residuos

Conoce de manera sencilla las categorías de residuos que puedes identificar y separar. La información está acompañada de símbolos y texto para facilitar su comprensión.

📄

Papel y cartón

Deposita materiales de papel y cartón limpios y secos.

🥤

Plásticos

Identifica envases y materiales plásticos reciclables.

🍾

Vidrio

Separa envases y recipientes de vidrio.

🥫

Metales

Identifica latas y otros materiales metálicos.

Consejo: revisa las instrucciones del punto de reciclaje antes de depositar tus materiales.

Puntos y recompensas

Cada participación puede registrarse mediante un código QR para acumular puntos. El sistema busca convertir el reciclaje en una actividad motivadora.

Accesibilidad: metodología POUR

El sitio fue estructurado considerando los cuatro principios de accesibilidad: Perceptible, Operable, Comprensible y Robusto.

👁️

Perceptible

Texto legible, contraste, estructura clara, iconos acompañados de texto y alternativas para contenidos visuales.

🖱️

Operable

Navegación sencilla, enlaces visibles, botones claros y acceso rápido a las diferentes secciones.

💡

Comprensible

Lenguaje sencillo, instrucciones paso a paso y nombres descriptivos para botones y secciones.

💻

Robusto

Estructura adaptable a diferentes tamaños de pantalla y organizada para facilitar el uso con tecnologías de asistencia.
